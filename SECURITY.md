# Security Policy

## Research scope

This repository documents infostealer techniques for **defensive research and
education**: detection engineering, lab analysis, and understanding modern
browser-credential protections. All tooling is intended for use solely on
machines you own, in isolated lab environments.

## Misuse

Do not deploy any code from this repository against systems you do not own
or lack explicit authorization to test. The authors accept no responsibility
for misuse and will not assist with operational use against third parties.

## Reporting vulnerabilities

If you find a genuine security issue in the defensive tooling itself
(e.g. the lab panel), open a GitHub issue with `[SEC]` in the title.
Reports of "this tool could be misused" restate the documented purpose of
the repository and require no action.

## Supported versions

Only the latest commit on `master` receives updates. There are no releases
and no long-term support branches.
